# Deep Agents Skills Glossary

本词汇表记录本学习工作区中已经能够使用的核心术语。定义会随着实验结果进一步修订。

## 核心概念

**Skill**：
面向特定任务的可复用能力包，通常包含 `SKILL.md` 指令，以及可选的脚本、参考文档和模板；它指导 Agent 如何组合 Tool 完成一类规范化工作流。
_Avoid_: 更大的 Tool、自动执行器

**Progressive disclosure（渐进式披露）**：
先加载 Skill 的元数据，再在任务匹配后读取正文，最后按需读取辅助资源的上下文管理方式。
_Avoid_: 一次性加载、延迟执行

**Tool**：
Agent 可以调用的一项原子操作，例如调用 API、搜索一次或读取一个文件；Tool 不等于完整的领域工作流。
_Avoid_: Skill、流程规范

**Memory**：
对很多或全部对话都持续相关的上下文，例如项目规范、用户偏好或长期背景；特定任务才需要的流程通常更适合放进 Skill。
_Avoid_: 临时提示词、任务脚本
