人直接提供工具结果

本课只区分 respond 与 reject。

两者都可以跳过工具，但含义不同

reject 表达“不执行这次请求”，并把拒绝反馈交给 Agent。respond 则由人直接提供结果：工具函数不执行，人的 message 作为成功的工具结果交给 Agent。它适合 ask_user 这类专门询问人的工具，不能用来表达拒绝发送、删除等操作。依据：LangChain 官方 HITL 文档。

一个例子

假设 Agent 调用 ask_user(question="报告标题是什么？")，人可以直接提供标题：

decision = {
    "type": "respond",
    "message": "项目进度报告"
}

这里的 message 是问题的答案。创建 Agent 时需要为 ask_user 开放 respond，例如 {"allowed_decisions": ["respond"]}。这是独立的人工输入工具配置，不沿用上一课 update_preference 的决策列表。

你来判断

现在 Agent 调用 ask_user(question="报告按月还是按季度汇总？")。用户回答“按季度”。应使用 respond 还是 reject？请在对话中给出选择，并用一句话解释。

作答后再自查

使用 respond，message 为“按季度”。用户是在回答问题，没有拒绝任务；人的答案就是工具结果。
