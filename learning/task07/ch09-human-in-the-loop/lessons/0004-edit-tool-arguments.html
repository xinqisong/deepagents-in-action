Chapter 09 · Lesson 04 · 5 分钟

同意执行，但先改参数

本课只练习填写 edit 中的一个参数。

接上拒绝反馈

如果不知道拒绝原因，可以把“请询问用户原因”作为下一步。上一题已知道用户要保留中文，因此可以直接反馈：“用户希望保留中文，拒绝改成 English；不要重试这次修改，请继续原来的任务。”

换一个需求

这次用户确实要求保存语言偏好，目标是中文。Agent 提出的 value 却是 English。用户同意执行，但需要先纠正这个值：使用 edit，工具会收到修改后的参数。依据：LangChain 官方 HITL 的 edit 决策。

先在创建 Agent 时开放 edit，再发起这轮新的练习：

interrupt_on = {
    "update_preference": {
        "allowed_decisions": ["approve", "edit", "reject"]
    }
}

这是新的配置示意，不表示上一轮已经暂停的任务会自动获得 edit 选项。

只补一个值

decision = {
    "type": "edit",
    "edited_action": {
        "name": "update_preference",
        "args": {
            "key": "language",
            "value": "_____"
        }
    }
}

name 指定工具，args 包含执行时要传入的参数。这里 key 的值是 language，表示修改语言偏好；只需要填 value，表示偏好的语言是什么。本例模拟工具接受中文字符串，不要求语言代码。

注意 edit 决策中的字段写作 edited_action.args。请保留其他参数，只填写目标语言。

作答后再自查

填“中文”。edit 表达的是同意按修改后的参数执行；后续仍要检查工具执行结果。
