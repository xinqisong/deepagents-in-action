工具请求是否已经执行？

接上你上一章提出的“敏感变更需要审批”：这次只练习判断，操作停在哪一步。

先看一个边界

模型生成工具名与参数，是提出执行请求。为该工具配置人工审批后，系统可以在调用工具函数前暂停，把请求交给人检查。看到模型的工具请求，还不足以证明写入已经发生。官方说明

模型提出请求 → 审批暂停 → 人工决定 → 获准后执行工具

你已知道如何检查 Store 的实际内容；这章沿用相同的证据习惯：同时观察请求和真实执行记录。

你来判断

假设这是一个全新线程，只有下面这一项工具请求。工具每次真正进入函数体，都会向 executed_calls 追加记录。

# 配置片段，不是完整运行程序
interrupt_on = {
    "update_preference": {
        "allowed_decisions": ["approve", "reject"]
    }
}

# 模型提出的请求
update_preference(key="language", value="English")

# 当前观察
存在待处理的审批中断
executed_calls == []
尚未提交任何人工决定
