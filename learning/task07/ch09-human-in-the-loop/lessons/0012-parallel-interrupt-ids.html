Chapter 09 · Lesson 12

两个独立中断，用 ID 回答

先前的批量工具审批是一个中断，内含两个 action_requests，按动作位置排列 decisions。这里是两个并行节点各自调用 interrupt()，产生两个独立的 Interrupt.id。恢复时将每个 ID 映射到对应答案。依据：LangGraph Interrupts。

运行 parallel_ids_demo.py：

learning/task07/.venv/bin/python learning/task07/ch09-human-in-the-loop/experiment/07-parallel-ids/parallel_ids_demo.py

脚本批准发布、拒绝归档，并打印恢复后的状态。这个例子只验证 LangGraph 的 ID 映射机制，因此不调用模型。
