把审批策略放在实际执行工具的子 Agent 上

主 Agent 只负责委派，发布工具仅交给 publisher 子 Agent。该子 Agent 自己的 interrupt_on 配置在 publish_draft 执行前暂停。审批策略随实际工具所在的 Agent 配置；恢复仍使用原来的线程与 Checkpointer。依据：Deep Agents HITL。

运行 subagent_approval_demo.py：

learning/task07/.venv/bin/python learning/task07/ch09-human-in-the-loop/experiment/08-subagent/subagent_approval_demo.py

检查暂停前内存发布记录为空，批准后恰好出现一次。真实模型可能改变委派路径；若没有中断，脚本会打印实际回复，不能把它记为通过。
